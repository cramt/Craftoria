Craftoria + Create Aeronautics

Craftoria 1.31.0 with Create Aeronautics, for Minecraft 1.21.1 / NeoForge 21.1.230.

Download Prism instance

Setup

  1. Install Prism Launcher.
  2. Download the zip above.
  3. In Prism: Add Instance → Import from zip → pick the file.
  4. Launch it. The first start downloads all the mods and takes a while.

Updates

There is nothing to re-download. The instance re-syncs itself from this page every time it launches, so you always get the current version.

If it asks for a manual download

A few mods block automated downloads. If launching stops and points you at a CurseForge page, save that file to the path it names inside your instance's mods folder, then launch again.
